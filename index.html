Browser Session Auditor

See stored session evidence. Understand what clearing browser data may disrupt.

Evidence, not a login guarantee. Cookies can outlive a server session. Saved passwords and passkeys cannot be inventoried here. This extension never displays, saves, or exports cookie values; Chrome’s API does temporarily return them to the scanner.

Website access

Choose sites to audit, or grant access to all HTTP(S) websites in this Chrome profile. No incognito or other profiles.

Clearing impact preview

Preview only. Nothing is deleted. Site-data clearing may affect storage this cookie inventory cannot see. Google sign-in cookies may be refreshed while Chrome stays signed in.

Page observation

Use “Check this page” from the toolbar popup on an HTTP(S) page to inspect visible logout controls and storage counts.

A visible logout control is a heuristic. Counts do not identify authentication tokens. Observations can become stale after navigation or logout; recheck from the popup.
